What it shows

Everything your box is doing.

Live metrics on a glance-able screen, plus a few things you won't find on a plain monitor.

CPU / GPU / mem / disk / net

Cores, VRAM, throughput, capacity — with temps and animated fans.

Local LLM server

Auto-detects llama.cpp, Ollama or vLLM — and names the one that’s live. Model, quant, context and tok/sec at a glance.

Claude Code usage

Token totals, active agents, and a live usage sparkline.

Kiosk mode

One command opens a full-screen Chromium dashboard — no desktop chrome. Say yes to the installer’s autostart prompt (or pass --autostart) and it comes up with your session.

Phone control panel

Switch themes and screens from your phone at :7777.

Graceful degradation

No GPU or sensors? Those readings show N/A — the layout stays put and nothing errors out.

Get running

One command, then a screen.

Grab a 7″ 1024×600 display, run the installer, point it at a box.

Monitor the local machine the display is plugged into.

curl -fsSL https://raw.githubusercontent.com/rohanprakash12/chiketi/main/scripts/install.sh | bash

Tip: grab a 7″ 1024×600 display (the GeeekPi panel is the reference) — but any HDMI screen works.

  1. Run the one-liner — it installs Python, pipx, sensors, and chiketi, and detects NVIDIA GPUs.
  2. Answer Enable autostart on login? — y starts it with every session, anything else keeps it manual.
  3. Plug in the display and run chiketi; it launches a full-screen Chromium kiosk.
  4. Open http://<host>:7777 on your phone to switch themes and screens.

Run on a Raspberry Pi and watch remote servers over SSH — nothing to install on them.

curl -fsSL https://raw.githubusercontent.com/rohanprakash12/chiketi-appliance/main/scripts/install.sh | bash

Tip: grab a 7″ 1024×600 display for the Pi — the dashboard renders on its HDMI out.

  1. Run the one-liner on a Raspberry Pi (or any Debian/Ubuntu box).
  2. Run chiketi-appliance; a browser setup wizard opens on port 7777.
  3. Add servers, drop in an SSH key, pick a theme — then start monitoring.
